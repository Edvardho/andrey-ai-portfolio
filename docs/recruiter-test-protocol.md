# Recruiter Test Protocol

## Goal

Check whether the portfolio helps a hiring person understand Андрей faster and with enough trust to start a conversation.

## Setup

- Recruit `3-5` recruiters, design leads, or hiring managers.
- Send one production URL without explaining the interface first.
- Ask each person to spend no more than five minutes.

## Tasks

1. `Кто такой Андрей и стоит ли звать его на интервью?`
2. Find one strong case and explain Андрей's personal contribution.
3. `Где доказательства по Альфа-Смарту или SIEBEL?`
4. `Был ли слабый кейс и какую ошибку он показывает?`
5. `Что Андрей делал в web и мобилке?`
6. `Как с ним связаться?`

## Questions After The Test

1. Стало ли быстрее понять кандидата, чем по обычному портфолио?
2. Доверяете ли вы ответам ассистента?
3. Что помешало бы использовать это при реальном найме?

## Notes Per Participant

| Field | Record |
| --- | --- |
| Participant role | Recruiter, design lead, hiring manager |
| Question and assistant answer | Verbatim or short factual summary |
| Where the person got stuck | Screen, question, or interaction |
| Contact reached | Yes / no |
| Trust score | `1-5` |
| Could name experience, a strong case, a risk, and personal contribution in 3-5 minutes | Yes / no |

## Decision Rule

Fix only a blocker or a problem seen by at least two participants. Do not add RAG, memory, a mobile version, an admin panel, or a redesign during this test cycle.
