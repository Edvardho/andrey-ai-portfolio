# Проверка full-context ассистента

## Что проверяется

Корпус содержит 60 рабочих сценариев и замороженные 40 отложенных сценариев: 28 одиночных вопросов и 12 диалогов по три ответа. Все сценарии синтетические и хранят ожидаемый смысл, допустимые источники, обязательные оговорки и запрещённые утверждения. Они не заменяют проверку нанимающими лидами.

Сравниваются три конфигурации:

- legacy на его текущей модели `gpt-4o-mini`;
- полное досье на `gpt-5.4-mini`;
- полное досье на `gpt-5.4`.

Ответы live-eval сохраняются только локально в `scratch/full-context-eval/`. Рабочие диалоги посетителей туда не попадают.

## Безопасный порядок запуска

Сначала выполнить бесплатную проверку:

```bash
npm run eval:full-context:preflight
```

Live-запуск не начнётся без явно указанного реального остатка бюджета:

```bash
npm run eval:full-context:live -- --configuration=gpt-5.4-mini --split=working --limit=12 --remaining-budget-usd=3.00
```

Допустимые конфигурации: `legacy:gpt-4o-mini`, `gpt-5.4-mini`, `gpt-5.4`. Явно переданные переменные окружения имеют приоритет над `.env.local`; файл загружается через Next env loader.

## Ограничение бюджета

Предварительный расчёт резервирует худший случай: вход до 32 тысяч токенов, выход до 2 тысяч токенов и две модельные попытки на ответ. Поэтому полный пилот и весь отложенный набор по всем трём конфигурациям не помещаются в лимит $10 в гарантированном худшем случае. Скрипт честно показывает это и не снижает критерии качества. Перед реальным прогоном нужно выбрать меньший пилот, уточнить остаток после фактических расходов и только затем резервировать следующий этап.

После пилота промпт и досье фиксируются. Отложенный набор нельзя использовать для их настройки. Ответы оцениваются вслепую без названия конфигурации; в отчёте нужны точные числители и знаменатели, p95 задержки, технические ошибки и фактические токены.
